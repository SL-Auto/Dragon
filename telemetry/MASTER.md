# Master telemetry requirements

This is an atomic event inventory. Each row identifies one concrete provider and event ID or normalized event type. `Supported tools` links to each tool's detailed telemetry file and counts the current rules that explicitly depend on the event/type, grouped by rule severity. `None` means the collection requirement is retained for analysis or compensation but no current rule explicitly depends on it. Counts are generated from rule metadata and exact event/type references, including documented normalized aliases.

## Maintenance rule

Whenever a detection or per-tool telemetry requirement changes, add or update its exact provider/event row, then run `scripts/update-master-telemetry-rule-counts.ps1`. If the same event supports another tool, add that tool to the existing row before regenerating counts. Do not replace event-level rows with a broad capability label, and do not merge separate event IDs merely because they support the same behavior.
